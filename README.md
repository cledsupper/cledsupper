# Olá, pessoas! 👋

## Eu sou programador de sistemas GNU/Linux, desenvolvedor de app e Técnico de T.I no IFRN.

### Meus principais projetos

1. [EmuBateria](https://cledsupper.github.io/): é um emulador de contador de carga que promete corrigir o percentual de carga em smartphones que sofrem de desligamento inesperado (desliga acima de 5%). Código será publicado mediante doações ao Leshto Batt para que eu possa investir no projeto;
2. [MoniBat](https://github.com/cledsupper/monibat): é um protótipo que analisou a viabilidade de construção do EmuBateria;
3. [libcells](https://github.com/cledsupper/libcells): uma biblioteca C para injeção facilitada de códigos em estruturas de dados e de tipagem dinâmica.
4. [xfce4-windowck-plugin](https://github.com/cledsupper/xfce4-windowck-plugin): é fork de um plugin para o XFCE que força os botões de janela a desaparecer do painel quando a janela maximizada está desfocada, evitando assim que o usuário feche acidentalmente a janela maximizada enquanto queria fechar uma janelinha sobreposta;
5. [Leshto Batt](https://gitlab.com/leshto-battery/leshto-batt): mais uma aplicação de monitoramento de bateria, mas desta vez, é apenas um monitor bem detalhado para o sistema Linux.
